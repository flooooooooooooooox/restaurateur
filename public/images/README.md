# Photos du site

Déposez ici les images fournies par le restaurant, puis activez les entrées
correspondantes dans `src/lib/site-data.ts` (tableaux `gallery` et `posters`).

Noms attendus (à adapter) :

| Fichier | Contenu |
|---|---|
| `crousty-plat.webp` | La box : riz, poulet croustillant, sauce |
| `salle-bornes.webp` | La salle, murs roses, bornes de commande |
| `frigo-boissons.webp` | Le réfrigérateur à boissons |
| `crousty-main.webp` | Une box servie à emporter |
| `affiche-compose.webp` | Affiche « Compose ton Crousty » |
| `affiche-sides.webp` | Affiche sides / boissons / desserts |
| `logo.webp` | Le logo Crousty Vice (fond transparent de préférence) |

Conseils : WebP, 1600 px de large maximum, moins de 300 Ko par image.
Chaque photo doit avoir un texte alternatif décrivant ce qu'elle montre.
